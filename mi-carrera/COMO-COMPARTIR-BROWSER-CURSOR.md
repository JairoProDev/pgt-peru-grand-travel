# Cómo dejo el navegador Cursor para que el agente revise

1. Abre el **Browser** dentro de Cursor (Simple Browser / panel Browser).  
2. Inicia sesión con `marketing@…` (tú apruebas 2FA).  
3. Deja abierta la pestaña que importa (Drive, GSC, GA…).  
4. En el chat escribe: “revisa Drive carpeta Seo” / “abre Search Console”.  
5. Si Google pide de nuevo verificación, **tú** la completas; el agente no usa tu TOTP.

No hace falta pegar contraseñas.
