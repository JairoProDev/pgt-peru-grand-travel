# Onboarding propio (PGT no tiene uno formal)

Tú construyes el onboarding. Ellos están abiertos pero no te guían paso a paso.

## Fases

| Fase | Días | Objetivo | Evidencia |
|---|---|---|---|
| 1. Supervivencia | 1–2 | Accesos, vocabulario, no romper nada | HECHOS, registro diario |
| 2. Mapa | 3–5 | Herramientas + Drive + bloque | VISION-GENERAL, GSC export |
| 3. Plan | 5–7 | Plan Clever + preguntas a equipo | PLAN-SEO enviado |
| 4. Migración SEO | sem 2–4 | URLs, staging, QA | mapa 301 |

## Cada mañana (10 min)

1. Leer `QUE-HACER-AHORA.md`  
2. Abrir `registro-diario/HOY.md`  
3. Una duda para un compañero (no guardar para siempre)

## Cada tarde (15 min)

1. Completar cronómetro del registro  
2. 3 líneas → HECHOS  
3. 1 insight → INSIGHTS (si aplica)
