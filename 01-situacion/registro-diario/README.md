# Registro diario — cómo justificar cada hora

**Objetivo:** demostrar onboarding productivo con evidencia, no con horas inventadas.

## Archivos del sistema

| Archivo | Qué va |
|---|---|
| `registro-diario/AAAA-MM-DD.md` | Cronómetro 5 min + entregables del día |
| `../HECHOS.md` | Solo cosas **verificadas** (viste, exportaste, te dijeron) |
| `../DUDAS.md` | Preguntas abiertas (para Ricardo, Clever, Lizet) |
| `../INSIGHTS.md` | Interpretaciones tuyas (puede estar equivocado) |
| `../VISION-GENERAL.md` | Mapa de la empresa (se actualiza semanal) |

## Regla de oro

- **Hecho:** "Entré a GSC y vi X clics en 28 días."  
- **Insight:** "Creo que el CTR bajo porque…"  
- **Duda:** "¿Staging Drupal tendrá las mismas URLs?"

## Al final del día

1. Completar `registro-diario/AAAA-MM-DD.md`  
2. Mover 3–5 líneas a HECHOS / INSIGHTS / DUDAS  
3. Si hay entregable: marcar en `05-marketing/PLAN-SEO-PARA-CLEVER-BORRADOR.md`
